## 0. 세 줄 요약

1. **`label = 1`은 독성 "없음"입니다.** 반대로 읽으면 모든 해석이 뒤집힙니다. 같은 데이터를 다룬 공개 블로그 분석이 실제로 이 실수를 했습니다.
2. **예측 신호는 기술자 4개가 아니라 구조(Fingerprint)에 있습니다.** 다만 가장 설명하기 좋은 신호는 **"지용성이 높으면서 염기성 아민을 가진 분자가 독성이 많다"**입니다.
3. **무작위 5-fold 점수는 믿으면 안 됩니다.** 비슷한 구조끼리 몰려 있어서 약 0.06 부풀려집니다. 구조 클러스터 분할로 검증해야 합니다.

## 3. 핵심 발견 5가지 (발표용)

### ① 라벨 방향 함정
강의안 p.11이 "Before modeling, always verify what the target label actually means"라고 경고합니다. 실제로 같은 데이터를 분석한 공개 블로그가 `label == 1`을 "독성 있음"으로 읽어서 clogp와 sa_score 해석이 모두 반대로 나왔습니다. **발표에서 이 사례를 들면 설득력이 있습니다.**

### ② 지용성(clogp)이 높을수록 독성이 많다
| clogp 구간 | 비독성 비율 |
|---|---|
| 1 이하 | 90% |
| 3 초과 | 46.7% |
| 6 초과 | 32% |

리핀스키 규칙 위반 개수가 늘수록 비독성 비율도 함께 떨어집니다(56.7% → 42.5%). "지용성이 높으면 간독성 위험이 크다"는 도메인 지식과 일치합니다.

### ③ 신호는 기술자가 아니라 구조에 있다
무작위 5-fold F1 기준입니다.

| 피처 | F1 |
|---|---|
| 기술자 4개만 | 0.703 (기준선 0.705와 같은 수준) |
| ECFP만 | 0.796 |
| FCFP만 | 0.799 |
| PTFP만 | 0.792 |
| 전체 | 0.816 |

### ④ 독성과 관련된 구조는 "염기성 아민", 비독성은 "카르보닐·카복실"
클래스 간 빈도 차이가 큰 ECFP 비트를 실제 부분 구조로 역추적한 결과입니다. 제공된 ECFP가 Morgan(반경 2, 1024비트)과 99.3% 일치해서 역추적이 가능했습니다.

여기에 ②를 결합한 **CAD 규칙(clogp > 3 그리고 염기성 아민 보유)**이 가장 강한 단일 파생변수입니다.

| 구분 | 비독성 비율 |
|---|---|
| CAD 해당 (47%) | **0.376** |
| CAD 미해당 | **0.694** |

clogp > 3 단독 기준(0.467 vs 0.742)보다 분리가 더 선명합니다. 지용성이 높으면서 염기성 아민을 가진 분자는 hERG 심장독성과 인지질증 위험이 크다고 알려진 조합입니다.

> **재현성 근거**: 두 명이 서로 독립적으로 파생변수를 만들었는데(27개 세트, 70개 세트) **양쪽 모두 이 규칙을 1순위 신호로 지목**했습니다.

### ⑤ 무작위 분할은 점수를 부풀린다
| 분할 방식 | F1 |
|---|---|
| 무작위 5-fold | 0.816 |
| 피처 중복 그룹 분할 | 0.815 |
| **구조 클러스터 분할** (Tanimoto ≥ 0.6, 2,233개) | **0.757** (−0.059) |

비슷한 구조가 train과 valid에 나뉘어 들어가면 모델이 "본 적 있는 분자"를 맞히는 셈이 됩니다. **모델 비교는 반드시 클러스터 분할 기준으로** 해야 합니다.

### 참고: 직관과 다른 결과 2가지
- **PCA는 쓰면 안 됩니다.** 분산 필터(3,076 → 1,013열)는 성능이 그대로지만, 여기에 PCA(분산 90%)를 더하면 F1이 0.618로 기준선보다도 낮아집니다. 희소한 작용기 정보가 뭉개지기 때문입니다.
- **MolWt는 U자형**입니다. 상관계수와 AUC(0.495)로는 아무 관계가 없어 보이지만, 구간별로 보면 양 끝에서 비독성 비율이 높습니다(300 이하 65.8% → 400~500 53.1% → 600 초과 60.2%). "상관이 낮으니 버린다"고 하면 안 되는 사례입니다.

## 4. 현재 모델 성능

구조 클러스터 5-fold(개발 7,151행) + 클러스터 단위 홀드아웃(1,198행, 마지막에 한 번만 평가) 기준입니다.

| 구성 | 홀드아웃 F1 | 홀드아웃 AUC |
|---|---|---|
| 제공 피처 + 기본 LightGBM, 임계값 0.5 | 0.756 | 0.791 |
| 정리된 피처 + 앙상블 + 임계값 튜닝 (파생변수 없음) | 0.770 | 0.806 |
| **+ 파생변수 (현재 최종)** | **0.784** | **0.817** |

**최종 구성**
- 피처: 상수·중복 비트 155개 제거(3,072 → 2,965) + 기술자 4개 + 파생변수 70개
- 모델: LightGBM · XGBoost · RandomForest 확률 평균
- 임계값: **0.39** (개발 OOF에서 F1 최대)

**성능 향상의 출처**: F1 +0.028 중 **임계값 조정이 +0.018**, 파생변수·모델이 +0.010입니다. 임계값 튜닝이 가장 효율이 좋습니다.

⚠️ **주의할 점**: 임계값을 0.5에서 0.39로 낮추면 더 많은 분자를 "안전"으로 판정합니다. 그 결과 Specificity(독성을 독성으로 잡아내는 비율)가 0.636에서 0.537로 떨어집니다. 채점은 F1로 되지만, 업무 관점에서는 **독성 물질을 안전하다고 오판하는 것이 가장 위험**합니다. 발표에서는 이 트레이드오프를 함께 밝히는 편이 좋습니다.

## 5. 확정된 모델링 방침

| 항목 | 결정 | 근거 |
|---|---|---|
| 검증 | 구조 클러스터 5-fold + 홀드아웃 | 무작위 분할은 0.06 부풀림 |
| 상수·중복 비트 | 제거 | 정보 없음, 성능 변화 없음 |
| 입체이성질체 중복 | **유지** | 제거·입체 피처 추가 모두 효과 없음 (F1 0.754~0.758로 동일) |
| 이상치 | 유지 | 실제 분자이고 신호가 있음 |
| 리샘플링 | 안 함 | 54:46으로 균형 |
| PCA | 안 씀 | F1 0.618로 기준선 미만 |
| 임계값 | OOF에서 F1 최대값 탐색 | F1은 임계값에 민감 |
| 학습 지표 | logloss/AUC로 학습, 임계값으로 F1 최적화 | F1은 불안정해서 학습 신호로 부적합 |

### 시도했지만 효과가 없던 것
- **RDKit 기술자 217개 전체 추가** → AUC 0.807에서 **0.798로 하락**
- MACCS keys, 입체 정보 피처 → 차이 없음
- Tanimoto SVM (AUC 0.748), 로지스틱 회귀 (0.784) → 앙상블에서 제외
- → **Mordred 기술자 1,600개 통째로 넣는 것도 같은 결과일 가능성이 높습니다.** 강사님도 "기술자 대량 추가는 후순위"라고 안내했습니다.
